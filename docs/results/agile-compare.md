- *Off the planned path* = distance from the line it was asked to fly (straight lines for waypoints / AUTO).
- *Behind the plan* = distance from where the trajectory said to be at that moment (trajectory methods only).
- ArduPilot parameters set for these laps (its limits opened up to fit the plan): `ATC_ANGLE_MAX` = 40, `PSC_NE_JERK` = 9.8, `PSC_D_JERK` = 9.8, `WP_ACC` = 5.66. Why: ArduPilot smooths every GUIDED target with a jerk limit (PSC_NE_JERK, default 5 m/s³). In our test a 30° square-loop plan (peak jerk 8.4 m/s³) streamed with the defaults diverged: 2.3 m off the path on average, 5.2 m at worst, 1 of 4 rings. A gentler 20° plan (4.2 m/s³) flew fine with the defaults.
- AUTO is ArduPilot's own planner given only the ring centres: it rounds corners its own way and doesn't know which way each ring faces.
